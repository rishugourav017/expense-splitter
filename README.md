# Expense Splitter App

🔗 **Live Demo:** https://rishugourav017.github.io/expense-splitter/

---

## 📌 Description

**Expense Splitter** is a simple, user-friendly web app that helps you split daily expenses among multiple people. Add a name and amount, and the app automatically shows the total and per-person share.

Perfect for trips, shared houses, PGs, and group expenses 💸

---

## 🧠 Features

✔ Add expenses with person name  
✔ Calculates **total expense**  
✔ Shows **per person share**  
✔ Simple, clean UI  
✔ Works on mobile & desktop

---

## 🛠 Built With

- HTML  
- CSS  
- JavaScript

---

## 📁 Usage

1. Open the web app:  
   https://rishugourav017.github.io/expense-splitter/  
2. Enter a **name** and **amount**  
3. Click **Add**  
4. See the list, total, and per-person split

---

## 💡 How It Works

Every time you add an expense:
- The list updates with that entry
- The **total** updates
- The **per person amount** recalculates (total ÷ number of entries)

Clicking **Add** with empty fields shows an alert.
